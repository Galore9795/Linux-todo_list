# Linux Todo Notes

把聊天里的任务变成 Linux 桌面上的便签，并通过 Apple Calendar 安排执行时间。

发一段文字或一张截图，整理成带描述的勾选清单。普通便签留在桌面，重要事项用图钉置顶，在工作时也能看见。

## 计划体验

- 从 Crosspet 右键菜单打开便签，随机柔和配色，自由拖动和缩放。
- 一句话记录，支持描述、清单、完成和恢复。
- 每张便签独立置顶，可收成简短标题条。
- 从不同项目的聊天写入同一份本地任务清单。
- 聊天中查看日历空档，确认后安排任务；便签显示执行时间和上次核对时间。

## 当前开发代码

已建立实验性 PyQt6 便签和 SQLite 存储，尚未达到上面的完整交付范围。安装 PyQt6 后，在仓库目录运行 `python3 -m todo_notes`。用 `python3 -m todo_notes add '标题' --body '内容' --source '原文'` 添加，`python3 -m todo_notes list` 查看，`python3 -m todo_notes update ID --deleted 0` 恢复删除，`python3 -m todo_notes export` 导出 JSON。数据位于 `$XDG_DATA_HOME/linux-todo-notes`（默认 `~/.local/share/linux-todo-notes`）。

已通过本机 X11 窗口层级检查、隔离 GNOME 桌面操作测试以及日历测试事件创建和更新；其余未覆盖的环境与操作见项目计划。

清单：在便签中输入项目并按回车添加，勾选完成，双击文字编辑；选中项目后可删除。命令行可使用 `python3 -m todo_notes item-add 便签ID '项目'`、`python3 -m todo_notes item-update 项目ID --done 1`；列表与导出包含项目 ID 和完成状态。自动化检查：`python3 -m unittest discover -s tests -v`。

便签上的“恢复”可找回删除的便签和当前便签中删除的清单项目；删除最后一张便签时会保留一个空白入口。命令行可用 `python3 -m todo_notes item-restore 项目ID` 恢复项目，`list --all` 和 `export` 包含已删除项目。

## 跨项目使用

运行 `scripts/install-local.sh`，安装 `~/.local/bin/linux-todo-notes` 和用户级 Codex skill。确保 `~/.local/bin` 在 PATH 中；新启动的本地 Codex 会话可发现该 skill。安装入口引用当前仓库位置，移动仓库后需删除这两个入口并重新安装。命令行可在任意目录运行；当前已通过独立临时数据目录的跨目录调用检查，已验证另一个本地 Codex 会话在不显式点名 skill 时发现并调用它。

时间与日历记录：`update ID --reminder-at ISO时间 --start-at ISO时间 --end-at ISO时间 --due-at ISO时间` 分别保存提醒、执行开始和结束、截止时间，时间须带时区偏移，空字符串可清除。便签显示这些时间、上次核对时间及写入状态。`calendar-check ID success|failed` 和 `calendar-write ID success|failed` 只记录实际日历操作的结果，不会访问日历；成功写入时须提供 `--calendar-id` 和 `--event-id`。失败保留已有事件关联和上次成功核对时间。聊天端日历实际读写流程仍需验证。

Crosspet 入口：运行 `python3 scripts/install-crosspet-menu.py` 将“桌面便签”及线条 SVG 图标加入已安装 Crosspet 的右键菜单。当前安装版本已接入；重启 Crosspet 后加载。若更新 Crosspet 后入口消失，重新运行脚本。便签仍可独立启动。

对话刷新信号：`scripts/prompt-refresh.py` 只触碰本地空信号文件，不读取或保存对话内容；运行中的便签监听信号并刷新，同时保留定时检查。支持的 Codex 环境可将此脚本配置为 `UserPromptSubmit` 命令钩子。按照 [OpenAI 钩子文档](https://learn.chatgpt.com/docs/hooks)，用户级非托管钩子需要在 `/hooks` 中审阅并信任；为遵守不打扰的要求，目前没有自动修改用户钩子配置或触发信任提示。普通 Chat 的自动触发未验证。

截图来源：创建便签时使用 `add '标题' --source-file /图片路径 --source '识别或整理的原文'`，程序把图片复制到本机应用数据目录并关联便签，原文件删除后副本仍在。JSON 导出包含副本路径，不包含图片本身；迁移数据时需同时备份 `sources` 目录。

本机 Crosspet 已更新至适配后的上游 1.3.8；详细验证状态见项目计划。

置顶按钮显示当前可执行操作（“置顶”或“取消置顶”），避免系统字体缺少图标时显示方框。

收起便签时只保留标题和常用操作；展开后恢复之前的尺寸，收起状态也会在重启后保留。

清单的“撤销”按当前便签本次打开后的顺序撤销添加、文字修改、勾选和删除；如果其他入口已修改该项目，会保留新内容。标题和描述仍使用输入框自带的 Ctrl+Z；重启后不保留撤销历史，已删除内容仍可通过“恢复”找回。

本机 Crosspet 已安装适配的 1.3.8 并重启，旧安装版本保留以便回退；Cursor 事件桥及 Grok 事件解析已适配；本机没有安装这两个客户端，尚未进行真实客户端验证或自动配置钩子。更新和测试详情见项目计划。

本地 Codex 跨项目测试：在另一个目录启动独立会话，通过已安装 skill 创建便签与清单成功。写入提交后会发送本地刷新信号，运行中的便签立即重新读取；定时检查仍作为后备。

钩子配置可用 `python3 scripts/hook-config.py` 生成：若用户级 `~/.codex/hooks.json` 不存在，可将输出保存到该文件；已有配置时把 `UserPromptSubmit` 项合并进去，保留原有钩子。新配置需在 Codex 的 `/hooks` 中审阅并信任。隔离测试使用一次性信任绕过选项验证了本地 Codex 的实际触发，不会为日常会话设置该选项；当前全局钩子仍未安装。

便签上的“时间”可分别编辑提醒、执行开始和结束、截止时间，按本机时区输入，留空表示未设置。保存只修改便签；若需要创建或调整 Apple Calendar 事件，仍需在聊天中安排。

标题、描述和尚未按回车提交的清单输入都会保存；重启便签后可以继续编辑。清单草稿按回车时与项目创建一起保存。

从 Crosspet 再次打开便签时，如果程序已运行，会唤回已有便签窗口；不会再启动一套独立程序。

已关联日历事件的便签修改执行开始或结束时间后，会显示“待更新日历”；原事件关联与上次成功核对时间保留。聊天中实际更新事件成功后才记录写入成功。

便签中的“导出”或 `python3 -m todo_notes export-archive /路径/备份.zip` 会生成本地 ZIP，包含所有便签、草稿、已删除记录及关联截图副本。包内 `notes.json` 使用相对路径；目前尚无一键导入，迁移前请保留原应用数据目录。

隔离 GNOME/X11 实测中，“显示桌面”时普通及置顶便签仍可见、可拖动与缩放，退出后恢复原置顶状态；此行为依赖 X11 和 xprop。真实多显示器热插拔仍待验证。

本机 X11 窗口顺序测试：普通窗口能遮挡未置顶便签；置顶后便签位于测试普通窗口和测试全屏窗口上层。此结果针对当前 GNOME/X11，不代表所有桌面环境行为相同。

便签恢复时及屏幕可用区域变化后，会将完全离开屏幕的标题栏移回可操作范围；多显示器热插拔仍需在真实设备上验证。

聊天安排时，可把刚读取的完整日历事件 JSON（数组或含 `events` 的结果）通过标准输入传给 `suggest-slots --day YYYY-MM-DD --zone Asia/Hong_Kong --work-start 09:00 --work-end 18:00 --duration 60 --buffer 15`，得到当天候选时段。此计算不联网、不写日历；需要使用实际工作时段和最新完整日历结果，确认后再写入。

已用隔离测试截图验证本地 Codex 能识别清单、创建便签并保留原图副本；不同聊天环境是否能访问本机附件取决于该环境的文件访问能力。

重建本机 Crosspet 1.3.8 适配包：准备原有定制 Linux 1.3.7 目录和官方 1.3.8 Git 检出，然后运行 `python3 scripts/prepare-crosspet-138.py --base 原目录 --upstream 官方检出 --output 新目录`。脚本校验上游提交、保留原目录中的定制、应用适配与便签菜单并生成校验清单，不会自动安装或覆盖已有输出目录。

从 Crosspet 菜单打开时，便签优先作为独立用户服务运行，关闭桌宠不会关闭便签；若系统没有可用的用户服务管理器，则直接启动。再次打开会唤回已运行的便签。

便签会分别显示文字与草稿的保存状态及日历写入状态。保存暂时失败时会保留输入并重试；未成功保存前关闭程序会丢失这部分内存输入。

保存了原文或截图的便签会显示“查看来源”，可阅读原文、预览截图，并用系统默认程序打开保存的原图副本。

空档计算已用真实日历查询结果进行过只读验证；示例工作时段仅用于测试，实际安排时应使用用户的时间偏好。

清单项目保存失败时会提示并保留未提交的输入；勾选或删除若遇到其他入口同时修改，会保留数据库中的新内容并提示重新操作。

便签还有未保存文字时，删除操作会先尝试保存；若仍失败，会保留便签并显示提示。

本机 GNOME/X11 的实测窗口属性表明：置顶会提高便签在当前工作区的层级，但不会自动让它出现在所有工作区。隔离 GNOME/X11 会话的截图显示，切换到另一工作区后普通和置顶便签都不显示，返回原工作区后可见。

日历写入若超时或结果不确定，使用 `calendar-write ID unknown`（若返回日历或事件 ID，也一并传入）；界面会显示“结果不确定，需先核对事件”。核对前不要重复创建，以免产生重复日程。

便签中的执行、提醒、截止及日历核对时间按本机时区显示；底层仍保留带时区的时间记录。

Crosspet 的 Cursor 钩子配置可用 `python3 scripts/cursor-hook-config.py --bridge 安装目录/integrations/cursor/cursor_bridge.py` 生成；脚本只输出配置，不修改已有 Cursor 设置。需要时应合并已有配置，再由客户端加载。桥接代码基于官方 1.3.8，保留上游 MIT 许可。

## 便签本与撕取

从 Crosspet 右键菜单打开“桌面便签”，进入便签本。选择已有便签，填写任务名称、内容和可选的截止时间；点击“保存到桌面”，或按住纸张顶部的拖拽条，将纸片拖到桌面并松开。松手后当前便签贴到该位置，拖动过程会显示预览；窗口会记住位置。便签本里的“新建”创建一张空白便签。可直接运行 `linux-todo-notes edit` 打开同一编辑页。

桌面便签是无边框纸张，底部有轻微翘起的纸边；顶部操作栏可拖动、隐藏、置顶、收起，更多操作在菜单中。可继续在桌面直接编辑文字和清单。编辑页输入会作为草稿自动保存在本机，切换便签或重启后可恢复；保存失败会保留输入并显示提示；不同入口修改不同字段时可合并，同一字段有冲突时不会覆盖。导出的备份也包含这些草稿。

自动检查：`python3 -m unittest discover -s tests -q`；隔离 GNOME/X11 操作测试：`./tests/run_nested_desktop.sh` 及 `./tests/run_nested_desktop.sh tests/manual_editor.py`。后者在独立测试桌面用鼠标事件验证拖拽落点，不操作用户当前工作区。
